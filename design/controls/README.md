# Loading screen controller reference

The controller shell in `src/loading.js` is adapted from Kenney Input Prompts 1.5A, `Xbox Series/Vector/controller_xboxseries.svg` (CC0). The original vector and license are saved here. The shell retains its original width/height ratio; the labelled controls, shoulder callouts and shading are drawn in the UI.

- Asset source: https://kenney.nl/assets/input-prompts
- Archive: https://kenney.nl/media/pages/assets/input-prompts/8de120163f-1783763952/kenney_input-prompts_1.5.zip
- Hardware reference: https://www.xbox.com/en-US/accessories/controllers/xbox-wireless-controller
- License: https://creativecommons.org/publicdomain/zero/1.0/

The diagram is inline vector markup, so displaying it requires no additional asset download.
